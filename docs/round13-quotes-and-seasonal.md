# الدفعة ١٣: «اطلب عرض سعر من ٣ مهنيين» + التذكيرات الموسمية

## ١) اطلب عرض سعر من ٣ مهنيين

**المشكلة اللي بيحلها:** الزائر بيكتب نفس الطلب ٣–٤ مرات لكل مهني، وبياخد وقت ومجهود.

**الشكل الجديد:**
- في صفحة أي قسم أو تخصص: زر برتقالي «اطلب عرض سعر من ٣» جنب عنوان المهنيين.
- نافذة بسيطة: اسمك · موبايلك · المنطقة (اختياري) · تفاصيل الشغل المطلوب.
- بعد الإرسال: قائمة بـ**٣ مهنيين** (أقل استلامًا للطلبات الأول حتى يتوزّع بالتساوي)،
  ومع كل واحد زر «واتساب» برسالة جاهزة فيها تفاصيل الطلب واسم الزائر ورقمه، وزر اتصال.
- الطلب بيتحفظ في `directory_quote_requests` (مع أرقام المهنيين اللي اتبعتلهم)،
  وبيوصل للإدارة كإشعار داخلي + تنبيه واتساب للمكتب.

**الملفات:** `src/lib/quotes.ts` · `src/app/api/quotes/route.ts` · `src/components/quote-request-modal.tsx` · `src/components/admin-quotes.tsx`

**في لوحة الإدارة ← إحصاءات:** بطاقة «طلبات عروض الأسعار» فيها كل طلب بتفاصيله ورقمه وعدد المهنيين.

## ٢) التذكيرات الموسمية الجاهزة

٩ تذكيرات مكتوبة وجاهزة، كل واحد بشهور محددة:

| التذكير | الشهور |
| --- | --- |
| صيانة التكييف قبل الصيف | أبريل · مايو |
| غسيل الخزانات قبل الصيف | أبريل · مايو · يونيو |
| تكييف السيارة | أبريل · مايو · يونيو |
| دروس ومدرسين قبل الدراسة | أغسطس · سبتمبر |
| نقاشة وتشطيب قبل العيد | مايو · يونيو · أغسطس · سبتمبر |
| استعداد رمضان | فبراير · مارس |
| السخان قبل الشتا | أكتوبر · نوفمبر |
| فحص الغاز قبل الشتا | أكتوبر · نوفمبر · ديسمبر |
| الأفراح والمناسبات في الصيف | مايو – أغسطس |

- في لوحة الإدارة ← إحصاءات: بطاقة «تذكيرات موسمية جاهزة» بتعرض المستحق الشهر ده، وتقدر تبعتُه لكل المشتركين بضغطة واحدة (نفس نظام الإشعارات)، مع قائمة «قادم في مواسم تانية».
- النصوص مظبوطة على حدود الإشعارات (عنوان ٦٠ حرفًا، نص ١٦٠ حرفًا) والروابط داخلية فقط.

**الملفات:** `src/lib/seasonal-reminders.ts` · `src/app/api/seasonal/route.ts` · `src/components/admin-seasonal.tsx`
