# الجولة 19 — الإعلان المتحرك بحجم الشريط + زر «مهنة ناقصة» أحمر

## الطلب

1. الإعلان المتحرك يكون **بعرض الشريط المتحرك** و**بنفس ارتفاعه**.
2. **القوالب الجاهزة** تتغير أحجامها لتناسب المقاس الجديد.
3. **إزالة زر «مهنة ناقصة» من الفوتر**، وتحويله لزر **بجوار «بحث» و«أضف مهنتك»**، بنفس مقاسهم، و**بلون أحمر**.

## اللي اتعمل

### 1) ارتفاع موحّد للشريطين

```css
:root { --strip-h: 50px; }          /* 48px على الموبايل */
.site-announcement-ticker-card { min-height: var(--strip-h); }
.ad-rotator-stage { height: calc(var(--strip-h) - 4px); }
```

- شريط الأخبار المتحرك والإعلان المتحرك بقوا **نفس الارتفاع**.
- الإعلان بقى **بعرض الشريط الكامل** (`width: 100%` و`max-width: none` بدل سقف 520 بكسل)، واتشالت الحواشي الداخلية والبوردر الزايد.
- المؤشرات (النقط) والبروجرس بار وبادج «إعلان» اتصغّروا وبقوا متراكبين جوّه الشريط بدل ما ياخدوا مساحة.
- زر «التفاصيل» الصغير اتشال (الضغط على الشريط نفسه لسه بيفتح التفاصيل).

### 2) القوالب الجاهزة اتصغّرت

- `.ad-art` بقى `height:100%` و`min-height:0` وحواشي 5px بدل 14px.
- أيقونة القالب الدائرية والبادج والأشكال الطايرة بتتخفي في وضع الشريط (مساحة أقل).
- العنوان: `clamp(0.8rem, 3cqw, 1.02rem)`، الوصف سطر واحد، وزر «شوف صفحته» أصغر.
- حالة «مفيش إعلان» بقت شريط أفقي بنفس الارتفاع (أيقونة + عنوان + الأزرار) بدل المربع الكبير.

### 3) زر «مهنة ناقصة» أحمر بجوار البحث والإضافة

- اتشال من فوتر الموقع.
- بقى **ثالث زر** في إطار البحث والإضافة (في الرئيسية وصفحات الأقسام والتخصصات).
- الإطار بقى ٣ أعمدة متساوية: `repeat(3, minmax(0, 1fr))` وكل الأزرار بنفس الارتفاع (54px، و50px على الموبايل).
- الزر بلون **أحمر متدرّج** (`#ef4444 → #b91c1c`) وكتابة بيضاء، وله نسخة أغمق في الوضع الليلي.
