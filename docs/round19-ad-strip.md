# الجولة 19 — الإعلان المتحرك بحجم الشريط + زر «مهنة ناقصة» أحمر

## الطلب

1. الإعلان المتحرك يكون **بعرض الشريط المتحرك** و**بنفس ارتفاعه**.
2. **القوالب الجاهزة** تتغير أحجامها لتناسب المقاس الجديد.
3. **إزالة زر «مهنة ناقصة» من الفوتر**، وتحويله لزر **بجوار «بحث» و«أضف مهنتك»**، بنفس مقاسهم، و**بلون أحمر**.

## اللي اتعمل

### 1) الإعلان المتحرك: عرض الشريط الكامل بنفس الارتفاع الأصلي

```css
.categories-top-action-stack .ad-rotator,
.ad-rotator { width: 100%; max-width: none; }        /* بعرض الشريط */

.ad-rotator-stage {
  width: 100%;
  aspect-ratio: 3 / 1;      /* نفس الارتفاع اللي كان */
  min-height: 110px;
  max-height: 240px;
}
```

- الإعلان بقى **بعرض الشريط الكامل** (`max-width: none` بدل سقف 520 بكسل).
- **الارتفاع رجع زي ما كان**: نسبة 3:1 بحد أدنى 110 وحد أقصى 240 بكسل — يعني حوالي **520×173** على الكمبيوتر و**~336×112** على موبايل 360.
- حالة «مفيش إعلان» رجعت لنفس النسبة والشكل العمودي.

### 2) القوالب الجاهزة

- القوالب رجعت لمقاسها الطبيعي (بادج + أيقونة + عنوان + وصف سطرين + زر) لأن الارتفاع بقى كافي تاني.
- مفيش أي تصغير أو إخفاء لعناصر القالب.

### 3) زر «مهنة ناقصة» أحمر بجوار البحث والإضافة

- اتشال من فوتر الموقع.
- بقى **ثالث زر** في إطار البحث والإضافة (في الرئيسية وصفحات الأقسام والتخصصات).
- الإطار بقى ٣ أعمدة متساوية: `repeat(3, minmax(0, 1fr))` وكل الأزرار بنفس الارتفاع (54px، و50px على الموبايل).
- الزر بلون **أحمر متدرّج** (`#ef4444 → #b91c1c`) وكتابة بيضاء، وله نسخة أغمق في الوضع الليلي.
