# الدفعة ١٥: الرسائل الترحيبية العائمة

ثلاث لحظات، وكل واحدة بشاشة عائمة أنيقة (كارت في نص الشاشة بخلفية معتمة):

| اللحظة | متى تظهر | المحتوى |
| --- | --- | --- |
| **عضو جديد** | فورًا بعد التسجيل (الرابط بيكمل `?welcome=member`) | ترحيب باسم العضو + ٣ خطوات سريعة + زر «ابدأ تصفّح الدليل» |
| **مهني قدّم طلب** | فورًا بعد إرسال طلب إضافة المهنة، وأي فتح لصفحة المتابعة/الحساب وهو لسه قيد المراجعة | «طلبك وصل وإحنا بنراجعه» + زر متابعة الطلب + طمأنة إن الرد على واتساب |
| **بعد موافقة الإدارة** | أول ما يفتح الموقع/التطبيق بعد الموافقة (حتى لو كان قافله وقتها) | احتفال + زر «شوف بطاقتك» + زر «حسابي وملصق QR» |

## إزاي بتظهر «مرة واحدة» وتفضل صحيحة لو التطبيق كان مقفول؟

- لكل مهنة عمود جديد `status_updated_at` بيتحدث **وقت تغيير الحالة** على الخادم (موافقة/رفض/استكمال بيانات).
- الموقع بيسأل `/api/welcome` عند كل فتح، ويقارن `(رقم المهنة + وقت تغيير الحالة)` بمفتاح محفوظ على الجهاز.
- أول ما يقابل تركيبة جديدة → يعرض الرسالة المناسبة ويحفظ إنها اتشافت.
- يعني: الموافقة حصلت والزائر قافل التطبيق؟ أول ما يفتحها تظهرله رسالة «مبروك مهنتك اتنشرت».

## حالات إضافية
- `needs-info` → «محتاجين استكمال بيانات منك» مع الملاحظة اللي كتبتها الإدارة.
- `rejected` → «مهنتك مش منشورة حاليًا» مع زر التواصل مع الإدارة.

## الملفات
- `src/lib/welcome-messages.ts` — نصوص الرسائل + مفاتيح «شوهدت» (منطق نقي قابل للاختبار).
- `src/components/welcome-modal.tsx` — الشاشة العائمة (Escape، تركيز، قفل التمرير، احترام تقليل الحركة، وضع ليلي).
- `src/components/welcome-center.tsx` — تقرير أي رسالة تظهر + نسخة خاصة بصفحة حساب المهني.
- `src/app/api/welcome/route.ts` — بيانات العضو وآخر مهنة مرتبطة برقمه.
- `src/app/my/[token]/page.tsx` و`src/app/track/[token]/page.tsx` — عرض الرسالة داخل صفحات المهني.
- `src/components/request-forms.tsx` — رسالة عائمة بعد إرسال الطلب مباشرة.
- `src/components/auth-form.tsx` — إضافة `?welcome=member` بعد التسجيل.
- `src/app/layout.tsx` — تركيب المركز على كل الصفحات.
- `src/db/schema.ts` + `src/lib/directory.ts` (`SCHEMA_VERSION = 2026-10-31.7`) — عمود `status_updated_at` بترحيل تلقائي.
- `src/app/janzour.css` — تنسيقات الشاشة العائمة.

## معاينة سريعة
افتح `/?welcome=member` على الموقع — هيظهر كارت الترحيب بشكله النهائي (من غير تسجيل).
