# الجولة ٢٥ — إحصائيات بأزرار وشاشات عائمة + إشعارات الأعضاء + إصلاح الأخطاء

## ١) صفحة «إحصائيات التفاعل والبحث» بقت أزرار مش أقسام متراكبة
- شبكة `analytics-tiles`: **١٦ زر** مستقل، كل واحد بأيقونته ولونه وعدّاده وزر «عرض …».
- الضغط يفتح **شاشة عائمة** (`Modal`) فيها محتوى القسم كامل، النص متوسّط، وزر إغلاق ✕ + Esc.
- الأقسام: الملخص العام، البحث والتفاعل، توزيع الأقسام، توزيع المناطق، الأعلى تقييمًا،
  تخصصات ناقصة، أرقام الاستخدام، التذكيرات الموسمية، إشعار الزوار، ترحيب المهنيين،
  ملصقات QR، أخطاء الموقع، صحة الدليل، مهن ناقصة، تقييمات سريعة، تقارير الأكواد.
- شاشة الملصقات تفتح مباشرة (هي نافذة بالفعل).

## ٣) أخطاء الموقع (من صورة السجل)
| الخطأ | السبب | العلاج |
|---|---|---|
| `Failed to load chunk …` | المتصفح بيطلب ملفات نسخة قديمة بعد نشر جديد | `ChunkRecovery`: تحديث تلقائي مرة واحدة (بحماية دقيقة) وفتح نسخة جديدة |
| `Error invoking postMessage: Java object is gone` | جسر WebView في متصفح داخل تطبيق (فيسبوك/أندرويد) | يُصنَّف «ضوضاء بيئة» ومش بيتخزن ولا يبعت تنبيه |
| `Script error.` | خطأ من سكربت خارجي (إضافة/حقن) بلا تفاصيل | نفس المعالجة + وصف عربي واضح |

`isEnvironmentNoise()` في `src/lib/error-report.ts` بتفلتر الأنواع دي قبل التخزين.

## ٤) إشعارات الأعضاء + تسلسل «تم الاستكمال»
- زر **جرس** في الهيدر لكل عضو/مهني مسجّل يفتح «إشعاراتي» مع عدّاد.
- «استكمال» من الإدارة → إشعار داخلي للمهني → يكمّل بياناته → يظهر له زر **«تم الاستكمال ✓»**
  (POST /api/my `completion-done` → الحالة `done` وإشعار للإدارة).
- في لوحة الإدارة زر «استكمال» يختفي ويظهر **«تم التنفيذ ✓»** (أخضر) — الضغط عليه يعتمد
  الاستكمال ويشيل الاسم من البطاقات الناقصة.

## ٥) ترحيب المهنيين الجدد
بجوار «رسالة ترحيب» (واتساب) و«ملصق QR» بقى فيه زر **«إشعار بالترحيب»** يبعت إشعارًا داخليًا
(provider notification) يظهر للمهني في «إشعاراتي».

## ٦) التذكيرات الموسمية + إشعار الزوار (شرح داخل الصفحة)
- صندوق «الرسالة دي بتروح فين بالظبط؟»: إرسال = **إشعار متصفح Web Push** لكل الأجهزة المشتركة،
  مش واتساب، ومش محتوى محفوظ في الموقع. ومعاه عدد الأجهزة المشتركة الآن.
- الموسوم القادمة بقت **كروت في عمودين** بنص متوسّط، والمستحق الشهر ده كارت بزر إرسال متوسّط.
- «إشعار الزوار (3)» فيه شرح كامل: الرقم = **عدد الأجهزة** المشتركة (مش الأشخاص)، مين بيشوفه،
  بيظهر إزاي، فين بيفتح، وبيختفي بعد ٧ أيام.
