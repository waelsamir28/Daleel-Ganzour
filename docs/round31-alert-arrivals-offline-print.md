# الجولة ٣١: تنبيه طارئ + «وصل حديثًا» + دليل ورقي + ملصق بيانات مكتملة + وضع بدون نت

## ١) شريط التنبيه الطارئ (أعلى كل صفحات الموقع)
- **للأدمن:** في «إعدادات الموقع» قسم جديد «شريط التنبيه الطارئ أعلى الموقع»:
  نص التنبيه (حتى ٢٠٠ حرف) + درجة اللون (أزرق تنويه / برتقالي تحذير / أحمر طارئ) + مدة الظهور
  (١، ٣، ٦، ١٢، ٢٤ ساعة أو «بدون انتهاء») + زر **«مسح التنبيه»** + معاينة حية للشريط.
- **للزائر:** الشريط يظهر فورًا أعلى الموقع في كل الصفحات، بلون الدرجة المختارة، وفيه زر إخفاء
  يخص التنبيه ده بس (لو الأدمن كتب تنبيه جديد يظهر من جديد).
- **ينتهي لوحده:** بعد المدة يختفي تلقائيًا من كل الأجهزة (حتى لو الصفحة مفتوحة).
- الملفات: `src/lib/emergency-alert.ts` (منطق نقي)، `src/app/api/site-alert/route.ts`،
  `src/components/emergency-alert-bar.tsx`، حقول جديدة في `SiteSettings` + `settingsInput` + `sanitizeSettings`.

## ٢) شريط «وصل حديثًا»
- شريط أفقي أعلى الصفحة الرئيسية بآخر **٧ أيام** من المهن والخدمات المنشورة (حتى ١٠ كروت):
  أيقونة التخصص، الاسم، القسم، العنوان، «النهاردة / إمبارح / من كذا يوم»، زر اتصال وزر تفاصيل.
- المميز لا يزاحم الوافدين الجدد (يظهر في الآخر داخل الشريط)، والطلبات غير المنشورة لا تظهر.
- الملفات: `src/lib/new-arrivals.ts`، `src/components/new-arrivals.tsx`، وإدراجه في `directory.tsx`.

## ٣) الدليل الورقي الشهري
- صفحة **`/print/guide`**: نسخة A4 جاهزة للطباعة/الحفظ PDF، فيها:
  - غلاف بهوية الموقع + «طبعة نوفمبر ٢٠٢٦» + ملخص «١٢٦ خدمة في ١٤ قسم» + تاريخ الطباعة.
  - كل قسم في جدول (الاسم/المهنة — الرقم — العنوان)، التخصص تحت قسمه، والنجمة للمميز، ✓ للتحقق.
  - الأقسام اللي ملهاش خدمات لا تُطبع، والترتيب بعدد الخدمات (الأكبر أولًا).
  - عمودان على الورق لتوفير الصفحات، وإخفاء الهيدر/الفوتر/الأزرار عند الطباعة.
- زر **«الدليل الورقي (طباعة)»** في قائمة لوحة الإدارة.
- الملفات: `src/lib/printable-guide.ts`، `src/app/print/guide/page.tsx` + `guide.css`،
  `src/components/print-guide-controls.tsx`.

## ٤) ملصق «بيانات مكتملة ✓»
- شارة خضراء على كارت المهني وفي صفحة المهنة تظهر لو البيانات مكتملة (عنوان + خدمات تفصيلية + تخصصات فرعية).
- المنطق: `isProfileComplete` في `catalog.ts` (نفس قاعدة شاشة الاستكمال)، والملصق في `provider-card.tsx`.
- الهدف: حافز لباقي المهنيين يكمّلوا بياناتهم — بيكمّل شغل جولة الاستكمال (٢٨).
