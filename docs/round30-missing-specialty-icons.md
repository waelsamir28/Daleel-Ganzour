# الجولة ٣٠: استكمال الأيقونات الناقصة في الأقسام

## طلب المستخدم
أيقونات ناقصة في قسم العيادات (الأورام، القلب والصدر، المخ والأعصاب، جراحة، الباطنة) كانت بتظهر
بسماعة رمادية عامة. المطلوب: استكمالها، ولفة على التطبيق لأي أيقونة ناقصة تانية.

## السبب
- التخصصات الجاهزة في الكتالوج (١٢٦ تخصصًا وقسمًا) كلها عندها ملصق WebP — اتأكدنا: **صفر ناقص**.
- الناقص هو التخصصات اللي **أنشأها الأدمن أو جت من استيراد Excel** بمعرّف عشوائي (UUID)،
  فمفيش ملصق بمعرّفها، ومطابقة الاسم كانت بتغطي ٤ حالات بس (موبايل/كمبيوتر/هدم/كاميرات)
  ⇒ الباقي كان بيرجع لأيقونة عامة بلون القسم (السماعة الخضراء).

## اللي اتعمل
### ١) أربع أيقونات جديدة بنفس أسلوب باقي الملصقات (256px WebP شفاف الزوايا)
| المعرّف | التخصص | الشكل |
| --- | --- | --- |
| `oncology` | الأورام | شريط بنفسجي لامع + خلية وردية على خلفية لافندر |
| `surgery` | جراحة | مشرط + ملقط جراحي على خلفية تركواز فاتح |
| `internal-medicine` | الباطنة | سماعة + كلوبورد بصليب أحمر على خلفية خوخي |
| `chest` | القلب والصدر | قلب أحمر + رئتين وردي على خلفية سماوي |

- الملفات: `public/images/specialty-stickers/{oncology,surgery,internal-medicine,chest}.webp`
- سكربت المعالجة: `scripts/sticker-square.py` (يقتطع البلاطة، 256px، زوايا دائرية 58، WebP q86).

### ٢) مطابقة الأسماء بقت شاملة (في `src/lib/catalog.ts`)
- `extraStickerIds` زادت الأربعة الجداد.
- `stickerNameHints` اتوسّعت من ٤ أنماط إلى **+٧٠ نمط** بترتيب «الأخص أولًا»:
  - طبي: الأورام ← جراحة ← الباطنة ← القلب/الصدر ← المخ والأعصاب ← المسالك ← الهضمي ← الغدد ←
    الأشعة ← العلاج الطبيعي ← التمريض ← الأسنان ← العيون ← الأنف والأذن ← العظام ← الأطفال ←
    المراكز الطبية ← المعامل ← المستلزمات الطبية ← الصيدليات ← البيطري.
  - خدمات ومهن: البرمجة، الجرافيك، الدعاية، الطباعة، التصوير، المحاسبة، العقارات، السفر، الحضانات،
    الهندسة/المقاولات، الطاقة الشمسية، الفلاتر، المغاسل، الترزي، الطباخين، الأمن، الجيم، الفنون،
    الأثاث، الأدوات، البقالة، الجزارة، الدواجن، الأسماك، المخابز، الخضار، الكافيهات، النقل،
    المحاماة، العقود، الأفراح، المدرسين، التنظيف، التكييف، الميكانيكا، الكهرباء، السباكة، النجارة،
    النقاشة، السيراميك، الألوميتال، الزجاج، الكوالين، الدش، التنجيد، الجبس.
- القديم زي ما هو: الأيقونة المرفوعة من الإدارة بتفوز دايمًا، وبعدها مطابقة المعرّف، وبعدها مطابقة الاسم.
