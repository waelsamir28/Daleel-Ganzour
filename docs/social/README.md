# صور السوشيال ميديا — دليل جنزور

صور جاهزة للنشر (1080×1350 — مناسبة لإنستجرام، فيسبوك، واتساب، لينكدإن) لكل جزء من التطبيق.
كل صورة عبارة عن موبايل بيوضح الشاشة الحقيقية بنفس الألوان والأسماء، وتحتها/جنبها دعوة + رمز QR للصفحة.

| الملف | الشاشة | الاستخدام المقترح |
| --- | --- | --- |
| `01-home.png` | الصفحة الرئيسية | منشور تعريفي بالتطبيق |
| `02-categories.png` | الأقسام والتخصصات | منشور «إيه اللي هتلاقيه في الدليل» |
| `03-specialty.png` | تخصص (السباكة) وبطاقات المهنيين | منشور إضافة مهنة/تسجيل |
| `04-telecom.png` | صفحة الأكواد | منشور الأكواد (شتاء/مصيف) |
| `05-gov.png` | الأرقام الحكومية والطوارئ | منشور أرقام الطوارئ (ستوري/حالة واتساب) |

## إعادة التوليد

```bash
pip install --break-system-packages pillow arabic-reshaper python-bidi
python3 scripts/make-social-cards.py
```

## كيف تضيف شاشة جديدة؟

في `scripts/make-social-cards.py` أضف دالة `screen_xxx(img, draw, x, y, w, h)` ترسم محتوى الشاشة،
ثم أضف سطرًا في قائمة `SCREENS` بالشكل:

```python
("05-profile", "صفحة المهني", "العنوان الكبير", "الوصف تحت العنوان", screen_profile),
```
