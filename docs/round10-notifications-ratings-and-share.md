## ١) إشعارات المتصفح (Web Push) — بتوصل فعلًا

| الملف | الوظيفة |
| --- | --- |
| `src/lib/push-shared.ts` | تحقق نقي من الاشتراك والرسالة والمواضيع + كشف الاشتراكات المنتهية (404/410). |
| `src/lib/push.ts` | إرسال فعلي بـ `web-push`، عدّ المشتركين، حذف الأجهزة الميتة، إشعارات تلقائية لمهنة جديدة/تقييم معتمد. |
| `src/app/api/push/route.ts` | `GET` (الحالة + المفتاح العام + مواضيع الجهاز) · `POST` (تسجيل) · `PATCH` (تغيير الأقسام) · `DELETE` (إلغاء) · `PUT` (بث للإدارة). |
| `src/components/notify-toggle.tsx` | زر «فعّل إشعارات الموقع» في الفوتر + اختيار الأقسام اللي تهمّ الزائر. |
| `src/components/admin-push.tsx` | في الإحصاءات: عدّاد المشتركين + كتابة الإشعار + تحديد القسم المستهدف. |
| `public/sw.js` | استقبال `push` وعرض الإشعار، والضغط عليه يفتح الرابط أو يركّز التبويب المفتوح. |
| `src/db/schema.ts` + `src/lib/directory.ts` | جدول `directory_push_subscriptions` + عمود `topics` (ترحيل تلقائي). |

**التفعيل (مرة واحدة):**

```bash
npx web-push generate-vapid-keys
```

ثم أضف في Vercel (أو `.env.local`):

```
NEXT_PUBLIC_VAPID_PUBLIC_KEY=...
VAPID_PRIVATE_KEY=...
VAPID_SUBJECT=mailto:admin@daleel-ganzour.vercel.app
```

بدون المفاتيح الميزة تختفي بهدوء من الواجهة ولا يحصل أي خطأ.

**إمتى بيتبعت إشعار تلقائيًا؟**
- الإدارة تنشر مهنة جديدة لأول مرة → «مدرس رياضيات جديد في جنزور» → الرابط يفتح القسم.
- الإدارة تعتمد تقييمًا → «تقييم جديد على الدليل» → الرابط يفتح بطاقة المهني.
- أي خبر يدوي من لوحة الإدارة (كل المشتركين أو قسم واحد).

الزائر اللي اختار أقسامًا معيّنة يوصله إشعار قسمه + الأخبار العامة؛ اللي مختارش يوصله كل حاجة.

## ٢) «اطلب عبر واتساب» برسالة جاهزة

`serviceWhatsappMessage()` بقت تكتب رسالة كاملة: تحية باسم المهني + إن الزائر وصل من دليل جنزور + الخدمة المطلوبة + المنطقة + رابط صفحته على الدليل.
مستخدمة في: بطاقة الخدمة (`provider-card.tsx`)، نافذة التفاصيل وزر الواتساب الرئيسي (`directory.tsx`)، البطاقة الرقمية (`business-card-modal.tsx`)، وصفحة الملف (`profile-view.tsx`).
`serviceDirectUrl(id)` تبني رابط البطاقة المباشر.

## ٣) بطاقة مشاركة لكل قسم وتخصص

`categoryOgImage()` بقت بترجّع صورة لكل قسم:
- الأقسام المعروفة: الصور الجاهزة في `public/images/og/` (نسخة `v=3`).
- أي قسم/تخصص جديد من غير صورة: بطاقة مولّدة على الخادم في `/api/og/category?name=…&color=…` بلون القسم واسمه (نفس هوية الموقع، خط Cairo المحلي بدون إنترنت).
- ألوان الأقسام في `SECTION_ACCENTS` + `sectionAccent()`.

مثال للمعاينة: `docs/brand/category-og-fallback.png`.

## ٤) ملصق QR لكل قسم (للطباعة)

`src/components/section-sticker-modal.tsx` + `src/lib/section-sticker.ts`:
تختار القسم → ملصق A6 بلون القسم «كل … في مكان واحد — امسح الكود» + رمز QR يفتح صفحة القسم.
تنزيل PNG أو طباعة A6 أو مشاركة للمطبعة. متاح من **لوحة الإدارة ← إحصاءات ← ملصقات QR للأقسام**.

## ٥) تقييم بضغطة بعد الاتصال/الواتساب

- `src/lib/quick-rating.ts`: تحقق من التقييم (١–٥ نجوم) + «اسأل مرة واحدة لكل جهاز».
- `src/components/quick-rating.tsx`: بطاقة تظهر بعد ٢٥ ثانية من أي ضغطة اتصال/واتساب (الحدث `janzour:contact` من `analytics-tracker.ts`).
- `src/app/api/ratings/quick/route.ts`:
  - العضو المسجّل → تقييم عادي ينتظر مراجعة الإدارة (نفس نظام التقييمات).
  - الزائر → تقييم مجهول بالنجوم فقط في `directory_quick_ratings`.
- `src/components/admin-quick-ratings.tsx`: متوسط الرضا + أكثر المهن تقييمًا في الإحصاءات.
