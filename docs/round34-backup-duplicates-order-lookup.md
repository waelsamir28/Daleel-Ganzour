# الجولة ٣٤ — نسخة احتياطية · فحص المكررات · «طلبي وصل فين؟»

## ١. النسخة الاحتياطية والاسترجاع
- شاشة جديدة في اللوحة: **نسخة احتياطية** (تاب في القائمة الجانبية).
- تنزيل كامل البيانات:
  - `GET /api/admin/backup?format=json` — ملف استرجاع كامل (خدمات، أقسام، عناوين، مناسبات، إعدادات، مظهر، اتصالات، تهاني، مرافق).
  - `GET /api/admin/backup?format=xlsx` — ملف Excel بأربع أوراق: المهن / الأقسام / العناوين / الإعدادات للمراجعة.
  - الصلاحية: **أدمن فقط** (٤٠٣ لأي حد تاني).
- الاسترجاع: `PATCH /api/admin` بجسم `{ type: "backup", action: "restore", values: <ملف JSON> }`.
  - يتحقق من `app = daleel-ganzour-backup` و`version ≤ 1` ووجود بيانات.
  - **بيضيف ويحدّث، مش بيمسح** — مفيش حذف لأي سجل موجود.
  - يحتاج تأكيد كتابي بكلمة **«استرجاع»** في الشاشة.
  - بيرجّع `{ ok, created, updated, skipped, message }` مع الدليل المحدّث.
- الملفات: `src/lib/backup.ts` (منطق نقي)، `src/app/api/admin/backup/route.ts`، `src/components/admin-backup.tsx`.

## ٢. فحص الأرقام المكررة
- تاب جديد **فحص الأرقام المكررة** في اللوحة.
- بيجمع المكرر في **مجموعات** بدل تحذيرات متفرقة:
  - `phone` = نفس الرقم (بما فيه الرقم الاحتياطي).
  - `name` = اسم شديد الشبه داخل نفس التخصص (بعد توحيد الألقاب والهمزات و«ال» التعريف).
- كل مجموعة معاها **«الأكمل»** المقترح للاحتفاظ به:
  منشور (+٤٠) ← موثّق ← صورة ← عنوان ← وصف ← خدمات وتخصصات ← رقم احتياطي.
- لكل سجل: تعديل، وللمكرر: حذف بضغطة (بيمر على نفس تأكيد الحذف العادي).
- فلاتر: «نفس الرقم فقط» و«فيها غير منشور». السجلات التجريبية مستبعدة.
- الملفات: `src/lib/duplicate-groups.ts`، `src/components/admin-duplicates.tsx`.

## ٣. «طلبي وصل فين؟»
- صفحة عامة `/track`: صاحب المهنة يكتب رقمه ويشوف حالة طلبه من غير ما يتصل بالمكتب.
- `POST /api/track/lookup` بجسم `{ phone }` — عام، محدود بـ**١٢ بحث في الساعة لكل IP**.
- بيرجّع فقط: الاسم **مقنّع** («أحمد م.»)، التخصص، الحالة (قيد المراجعة / تم النشر / مرفوض / محتاج استكمال)، التواريخ، وملاحظة المراجعة.
- المنشور فقط له رابط عام (`/profile/...`)؛ المحتاج استكمال بيظهر معاه تنبيه يفتح رابط المتابعة الخاص.
- الصيغة المقبولة: `010/011/012/015` بـ١١ رقم، أو `+20` / `0020`، أو أرقام عربية.
- الملفات: `src/lib/order-lookup.ts`، `src/app/api/track/lookup/route.ts`، `src/components/order-lookup.tsx`، `src/app/track/page.tsx` + `track.css`.
- لينك «طلبي وصل فين؟» اتضاف في فوتر الدليل.
